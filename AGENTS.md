# Agent instructions for activity

Read [CONTRIBUTING.md](CONTRIBUTING.md) first. This repo is public.

## Rules agents break most here

- Do not add client names, client figures, internal hostnames, credential names or infrastructure paths. Check every line before you commit.
- Publish nothing without the ARC owner's approval.
- Keep month pages at `YYYY/MM-<month>/README.md` and link them from the front page.
- Open each changed page in a browser before you open the pull request.
